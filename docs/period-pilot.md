# 11월 11일 데이터 검증 · 2015~2025년

반도체·AI·바이오·양자의 샘플 토픽 T10472·T11636·T10878·T10682를 그대로 사용해 2015~2025년 한국 기관 참여 논문을 수집했습니다. 각 분야는 하위 토픽 하나로 정의한 기간 검증 범위입니다.

| 분야 | 수집 논문 | 최종 유지 | 기관 쌍·분야 수 | 양수인 기관 쌍·연도 행 |
|---|---:|---:|---:|---:|
| 반도체 | 1,865 | 275 | 560 | 712 |
| AI | 964 | 219 | 970 | 1,066 |
| 바이오 | 1,001 | 279 | 872 | 1,090 |
| 양자 | 726 | 260 | 512 | 637 |
| 합계 | 4,556 | 1,033 | 2,914 | 3,505 |

토픽·연도 44건의 조회 건수와 고유 논문 수가 일치했습니다. 중복 논문 ID는 0건이며 기관 50곳 초과 논문 7편을 제외했습니다. 국내 교육·시설·정부 기관의 논문 수를 기간 전체에서 세어 5편 이상인 기관 57곳을 유지했습니다. 해외 기관은 1,391곳입니다.

목록 응답에서 저자가 100명까지 표시된 논문 6편은 단건 조회로 소속을 확인했습니다. 양자 2023년의 최초 실패는 단건 확인을 반영한 뒤 재수집에 성공했습니다. 목록 원본과 단건 원본을 저장하고 조회 이력을 로그에 남겼습니다. [OpenAlex 소속 정보](https://help.openalex.org/data/authorships/)

## 주입 대상 확보 여부

2015~2020년의 6개 연도를 사용했습니다. 완료된 조회에서 해당 기관 쌍의 논문이 없던 연도는 0편입니다. 연평균 3편 기준은 6년 합계 18편에 해당합니다.

자격을 충족한 쌍은 0쌍이며, 가장 높은 쌍은 합계 16편(연평균 약 2.67편)입니다. 이 데이터에서 공통 조건의 20쌍을 확보하려면 분야별 대표 토픽 범위를 확대해 다시 집계해야 합니다. MANIFEST.json에 상위 기준선과 부족한 쌍 수를 기록했습니다.

탐지기 PR #4의 코드로 32,054행 시계열과 후보 수 0쌍을 대조했습니다. 같은 원본에 z-score(k=3, 임계값 2.0·2.5·3.0)는 41·31·21건, 전년 대비 증가율(최소 3편, 임계값 50%·100%·200%)은 18·13·9건을 탐지했습니다. 이 수치는 원본 데이터에서의 탐지 건수입니다. [탐지기 PR](https://github.com/Web-base-system-project-1/webbasesystem_project1/pull/4)

## 데이터 사용

- collab_counts.csv와 kr_totals.csv는 건수가 양수인 행을 담습니다. 탐지기는 두 파일로 2015~2025년 패널을 구성합니다.
- collab_shares.csv는 한 번이라도 나타난 기관 쌍·분야마다 11개 연도를 담습니다. 공동논문이 없으면 0편이고 국내 국제 공동논문 총수가 0이면 협력 비중은 빈 값입니다.
- institutions_kr.csv와 institutions_foreign.csv는 기관 이름·유형 또는 국가를 기관 ID로 연결합니다.
- pair_contributions.csv와 total_contributions.csv는 집계에 기여한 고유 논문을 확인하는 근거입니다.
- collection_coverage.csv는 토픽·연도별 수집 완료 상태와 건수입니다. preprocess_audit.csv에는 논문별 제외 판정이 있습니다.
- injection_candidates.csv는 조건을 충족한 기관 쌍의 표입니다. 이번에는 열 이름만 있습니다.
- MANIFEST.json에는 범위, 원본 해시, 집계 요약, 파일별 해시가 있습니다. 데이터 버전은 원본과 집계 파일의 해시를 반영합니다.

공유 ZIP을 풀면 집계 CSV, MANIFEST.json, 검증 기록을 사용할 수 있습니다. Flask를 실행하기 전에 DATA_DIR에 집계 폴더를 지정합니다. 압축을 푼 환경에서는 해당 폴더의 절대 경로를 사용할 수 있습니다.

~~~dotenv
DATA_DIR=data/processed/four_fields_2015_2025_20261111
~~~

/api/meta와 /api/pairs?field=quantum으로 범위를 확인한 뒤 /api/timeline에서 기관 쌍의 11개 연도를 조회할 수 있습니다. 현재 React 화면의 해외 기관 일괄 조회는 1,000곳으로 제한되어, 이번 1,391곳을 화면에 연결하려면 기관 목록 조회 보완이 필요합니다.

## 다시 수집하고 집계하는 방법

가상환경을 활성화한 뒤 프로젝트 최상위에서 실행합니다. config/field_definition.csv를 읽어 토픽·연도별로 커서를 끝까지 조회합니다. 다른 토픽 초안은 --definitions로 지정할 수 있습니다. [OpenAlex 커서 페이지 방식](https://help.openalex.org/api/paging/)

~~~bash
python -m pipeline.collect_period --output-dir data/raw/four_fields_2015_2025_20261111
python -m pipeline.aggregate_period --input-dir data/raw/four_fields_2015_2025_20261111 --output-dir data/processed/four_fields_2015_2025_20261111
~~~

중단된 수집은 같은 원본 경로로 다시 실행합니다. 해시와 조회 조건이 맞는 완료 폴더를 재사용하고, 미완료 토픽·연도부터 조회합니다. 원본을 새로 수집하거나 같은 원본을 재집계할 때는 각 출력에 새 폴더를 지정합니다.

원본 폴더의 collection_log.csv는 전체 조회 이력이며 logs 폴더에 실행별 이력을 보관합니다. 집계는 44개 완료 기록과 파일 해시를 확인한 뒤 0건 연도를 채웁니다. 원본 소속에서 다시 계산한 논문별 기여·연도별 분자·분모·비중과 집계 결과가 일치했고, 같은 원본으로 재집계한 CSV 해시도 일치했습니다.
