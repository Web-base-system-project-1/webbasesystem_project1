# API 명세

로컬 기본 주소: `http://127.0.0.1:5001`

## 현재 구현된 주소

| 메서드 | 경로 | 응답 |
|---|---|---|
| GET | `/` | 메인 HTML |
| GET | `/api/health` | `200`, `{"status": "ok"}` |
| GET | `/static/...` | JavaScript·CSS 파일 |

프론트엔드는 상대 경로 `/api/...`를 사용합니다. Flask가 화면과 API를 같은 주소로 제공하므로 초기 구성에 별도의 프론트 서버나 CORS 설정은 필요하지 않습니다.

## 추후 팀에서 확정할 API

아래는 설계 제안이며 아직 구현되지 않았습니다.

| 메서드 | 경로 예시 | 목적 |
|---|---|---|
| GET | `/api/institutions` | 기관 검색·유형 필터 |
| GET | `/api/timeline` | 기관 쌍·분야별 시계열 |
| GET | `/api/detections` | 탐지 목록·근거 |
| POST | `/api/whatif` | 설정 변경에 따른 탐지·평가 재계산 |
| GET | `/api/comparison` | 보정 전후 비교 |

각 API의 쿼리·본문·응답 예시와 결측 처리 규칙은 2·3·4번 담당자가 합의한 후 이 문서에 추가합니다.
